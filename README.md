## 🚀 Featured Architecture — CloudForge Platform

**CloudForge** is my self-directed cloud-native platform engineering project, designed around modular services, shared platform standards, identity management, AI/RAG workloads, and automated governance.

The project focuses on applying real-world engineering principles such as:

- Microservices architecture
- Cloud-native application design
- Centralized identity and authentication
- JWT / JWKS / scope-based authorization
- RAG and knowledge pipelines
- Infrastructure and platform governance
- Policy-as-code and automated validation
- CI/CD and DevSecOps practices
- Security-by-design
- Reusable shared platform components

| **Knowledge Studio** | RAG-oriented knowledge processing and retrieval architecture |
| **Security Studio** | Security-focused service and enforcement capabilities |
